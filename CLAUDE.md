Standing reminder: on every product iteration, update the end-to-end test plan in
`tests/e2e/TEST-PLAN.md` — add a row and a tagged Playwright test for each new or changed
user-facing behavior, remove the row and test of anything removed — and run
`npm run e2e-plan`. The rules are in the "End-to-end test plan" section of `AGENTS.md`.
